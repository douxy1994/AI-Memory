# Fluent UI System Icons

The SVG files in this directory are unmodified regular 20 px icons from
Microsoft's Fluent UI System Icons project:
https://github.com/microsoft/fluentui-system-icons

They are distributed under the MIT License. The selected source icons are:
Clipboard Task List LTR, Dismiss, Delete, Arrow Collapse All,
Arrow Expand All, Dual Screen Group, and Filter.
The settings About entry also uses the Fluent Info icon.
