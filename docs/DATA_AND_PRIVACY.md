# 数据与隐私

## 默认本地优先

AI Memory 的索引、记忆、检查点、交接和设置默认保存在本机。应用不会因为安装或首次启动自动把对话上传到第三方服务。

## 外部数据读取

- Agent/CLI 历史默认只读；
- ChatMem 导入从源路径通过 SQLite 在线备份接口只读复制，不修改源数据库，
  且会包含来源库已提交但尚未 checkpoint 的 WAL 变更；
- 迁移到另一个 Agent 前会检查目标是否支持安全写入；
- 删除会先进入 AI Memory 的可恢复回收站；无法安全写回的来源会明确保留原始历史。

## 同步

WebDAV 或本地文件夹同步必须由用户配置或主动触发。同步采用记录级增量清单，避免每次上传整个数据库。启用前应确认同步服务的隐私政策、账号安全和存储位置。

## 凭据

- macOS：WebDAV 密码保存在 Keychain；
- Windows：WebDAV 密码保存在 Credential Locker；
- 设置 JSON 不应包含明文密码；
- 日志、README、Issue 和诊断报告不得包含真实密码或访问令牌。

## 备份与恢复

- 数据迁移、数据库替换和 ChatMem 导入前建立恢复点；
- ChatMem 导入只在临时副本完成架构迁移与完整性检查后才替换当前数据库；
- 备份清单记录版本和内容哈希；
- 未变化文件可以通过复用方式减少空间；
- 损坏或版本过高的数据不会直接覆盖当前数据库。

## 默认路径

| 平台 | 数据目录 |
| --- | --- |
| macOS | `~/Library/Application Support/AIMemory` |
| Windows | `%LOCALAPPDATA%\AIMemory` |

卸载应用不会自动删除这些数据。删除前应先在设置中导出或备份。
